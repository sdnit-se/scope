# Shebang's fork of Twenty

This is Shebang's unofficial fork of [Twenty](https://github.com/twentyhq/twenty), the open-source CRM. It is not affiliated with or endorsed by Twenty.com; "Twenty" is their trademark.

It is the source of the modified Twenty that Shebang runs, offered to everyone under the same licence as upstream: see [LICENSE](LICENSE) (AGPLv3, with the exceptions it lists).

- `main` is the official release Shebang runs (tag `twenty/v2.54.0`) plus Shebang's own changes, one reviewed commit each.
- See every change with `git log twenty/v2.54.0..main`.
- Changes that help everyone are offered back to Twenty where they fit.
